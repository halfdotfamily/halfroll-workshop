# Animated ocean animals

Models by **Quaternius**, Animated Fish Pack (April2018), CC0-1.0.

- Author: https://quaternius.com/packs/animatedfish.html
- Author-uploaded source mirror: https://opengameart.org/content/animated-fish
- Download: https://opengameart.org/sites/default/files/Animated%20Fish%20Pack%20by%20%40Quaternius.zip
- License text: LICENSE.txt (original pack), https://creativecommons.org/publicdomain/zero/1.0/

Six original Blender models were converted to self-contained GLB with Blender5.2 using tools/export-sea-models.py. Original swim rigs/clips, topology and multi-material regions are retained. Legacy material nodes are rebuilt from the supplied OBJ/MTL diffuse colors. The browser applies a restrained blue/cream palette to the large animals. Fish retain the authored color regions. No external texture requests, Draco decoder or remote runtime dependency.

The source ZIP is kept under ignored output/sea-assets; the runtime GLBs and manifest are versioned here. Full six-file transfer is under420KB. Models are decorative; they never affect rules, player identity, funds or game randomness.
